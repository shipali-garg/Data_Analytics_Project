**HR Analytics To Track Employee Performance**

This project performs HR Analytics to analyze and predict employee performance based on key workplace and personal factors.
The goal is to help organizations identify performance drivers, recognize high performers, and make data-driven HR decisions.

Dataset Used:
Name: employee_performance_data_categorical.csv
Source: https://www.kaggle.com/datasets/ziya07/enterprise-hr-performance-dataset/data?select=employee_performance_data_categorical.csv
